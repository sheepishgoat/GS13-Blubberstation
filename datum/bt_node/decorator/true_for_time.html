true_for_time
/datum/bt_node/decorator/true_for_time

Passes while its duration has not elapsed, then fails reactively via observer abort. Starts timing on the first tick; resets when the tree resets.

duration: how long to pass, in deciseconds (e.g. "10 SECONDS"). Set observer_abort to BT_ABORT_BOTH (or BT_ABORT_SELF) to abort the child when time expires.
